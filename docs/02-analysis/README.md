# 分析模型

[SRS 建模文件](srs-models/README.md) 包含从 SRS 原始 Word 图形提取的 10 张可编辑模型，覆盖系统上下文、核心对象关系、UC01–UC20 用例、主要业务流程和辅助提取的人工确认边界。

直接用 diagrams.net / draw.io 打开 [合并建模文件](srs-models/KaiXu_SRS_Models.drawio)。逐图源文件位于 `srs-models/individual/`，SVG 预览位于 `srs-models/exports/`。

后续新增的 CRC、类图、状态图等分析成果继续保存在本目录，并保留可编辑图源与导出图。
