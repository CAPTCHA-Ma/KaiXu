# 工作区概览：重复事件课次验证

关联 #10。工作区概览曾直接显示重复序列的首条记录，无法展示当前周的课次。此修复复用日程模块的重复规则展开，显示近七个自然日的课次；一次性事件仍沿用原有列表范围。已取消的课次不显示，改动工作区的课次归入其最终工作区。点击课次使用原序列及所选日期进入现有编辑器。

新增自动化用例设计覆盖工作区与本人隔离、原始日期和近期课次不同、取消例外、课次跨工作区和时间窗口移动、跨午夜及编辑器保留课次日期和提醒。重复事件的账号同步仍由 #11 跟踪。

截至目前，测试尚未全部通过：本地离线构建缺少 Kotlin Multiplatform 2.2.20 插件依赖，联网构建因电脑内存不足而停止。首次 GitHub Actions 的共享测试 124 项中 5 项失败：4 项旧测试替身已调整，另 1 项原有日程测试曾报数据库锁。第二轮共享测试通过；桌面测试 25 项中 1 项因新测试误用文本匹配断言失败，现已修正断言，保存后核对提醒的验证仍保留。以新一轮 CI 结果为准。
