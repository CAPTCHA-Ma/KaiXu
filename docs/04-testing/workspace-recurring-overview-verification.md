# 工作区概览：重复事件课次验证

关联 #10。工作区概览曾直接显示重复序列的首条记录，无法展示当前周的课次。此修复复用日程模块的重复规则展开，显示近七个自然日的课次；一次性事件仍沿用原有列表范围。已取消的课次不显示，改动工作区的课次归入其最终工作区。点击课次使用原序列及所选日期进入现有编辑器。

新增自动化用例设计覆盖工作区与本人隔离、原始日期和近期课次不同、取消例外、课次跨工作区和时间窗口移动、跨午夜及编辑器保留课次日期和提醒。针对单次持续时间超过展开器限制的事件，按序列和自然日分段展开，并补充跨分段、近期课次和其他序列不受影响的测试；超长连续重复事件仍可能产生大量合法结果，存在性能风险。重复事件的账号同步仍由 #11 跟踪。
