## 1. 空间身份与生命周期

| 模式 | 身份与存储 | 工作区行为 |
| --- | --- | --- |
| LOCAL | 独立空间 ID、本地操作者 UUID、独立 SQLite 文件 | 本地事务保存，显示“独立本地”，保存成功后可显示“已保存到本地” |
| ACCOUNT 桌面 | 账号 ID、空间 ID、该账号专属 SQLite 文件 | 常规读写通过账号本地库，离线修改与待同步命令一起保存 |
| ACCOUNT 安卓 | 当前已认证账号及有效在线会话 | 读取服务器授权摘要/详情，业务操作由服务器确认 |

登录成功后切换到账号空间。独立空间的原记录保持在原数据库，只有用户主动确认导入时，才将选定记录及关联图复制成新的账号对象。导入过程应保存旧 ID 到新 ID 的映射并校验跨对象引用，属于账号/导入模块提供的能力。

当前 LOCAL_ACTOR_ID 是既有本地演示身份。账号记录的 owner_user_id、updated_by 等字段由已绑定的账号上下文产生，服务器再按认证身份和当前成员资格核验。客户端传入的 owner ID 本身不构成授权依据。

账号模块拟提供不可变的 `SpaceContext(spaceId, mode, accountId?, generation)`。generation 在登录、退出、换号、重新绑定数据源时推进。命令、查询、Flow 订阅和回调均携带或绑定这一上下文。

换号/退出按以下顺序协调。

1. 使旧 generation 失效，清空当前工作区、目录、概览、详情、草稿及返回栈中的受限显示内容。
2. 取消旧订阅和请求。已经提交的本地事务在原账号库完成，关联队列继续保留。数据库关闭需等待使用它的事务结束。
3. 新上下文绑定目标空间数据库后，再加载该空间的数据。任何迟到响应在更新页面、合并快照或推进同步游标前核对空间和 generation。
4. 显式退出后锁定账号库并停止其后台工作。再次登录同一账号后可继续未完成同步。会话失效时保留本地成果，暂停远端提交并转入重新认证流程。

## 2. 工作区命令与同步结果

账号空间内的创建、修改名称/说明、建立/解除/改选关联、归档和恢复，分别作为一个可重试的业务动作提交。同一 SQLite 事务写入工作区变更和 sync_outbox，任一失败则全部回滚。UI 只在该事务成功后关闭编辑表单并显示本地成功结果。

本地校验或事务失败时保留尚未提交的表单。若本地已经保存，随后服务器因字段、版本或目标状态拒绝命令，则显示失败或冲突，保留仍有权访问的待处理修改并提供比较、修正入口，不要求原编辑表单仍处于打开状态。修正后的提交沿用 UC20 的新操作及依赖规则，不改写已发送命令；明确失权的受限正文按第 5 节清理。

命令最少包含 operationId、当前空间、动作类型、目标 ID、所编辑对象的服务器基准版本与本地版本、白名单字段和必要依赖。新建对象由客户端生成 UUID，服务器接受后保留同一 ID。先创建课程再创建关联项目时，项目命令依赖课程创建结果。解除关联与其他字段修改属于同一次编辑命令。

已发送命令的 operationId 和正文保持固定。响应丢失后按原 ID 查询回执或重试。发送后产生的新编辑另建依赖命令，旧确认只能确认对应本地版本。服务器在一次事务内完成业务变更、operation_receipt 和受影响范围版本递增。

UI 状态按以下含义映射，由同步模块提供依据。

| 状态 | 允许显示的结果 |
| --- | --- |
| LOCAL_ONLY | 独立本地空间，内容仅保存在本机 |
| PENDING | 本地事务已提交，等待服务器确认 |
| SYNCING | 对应操作正在提交/查询回执，展示层从同步进度派生 |
| SYNCED | 服务器已确认当前展示的全部相关修改 |
| CONFLICT | 保留本地修改及基准/服务器值，等待用户处理 |
| FAILED | 展示可理解的失败原因及重试入口，保留已提交的本地成果 |

工作区归档状态 ACTIVE/ARCHIVED 与同步状态独立。归档/恢复、普通编辑和同步确认都保留记录 ID 与 created_at。全局页面、工作区列表、关联项目和详情以同一正式记录 ID 导航。

同步模块提供完整快照的 scope_key、revision、complete 标记和授权范围。本地事务成功合并后才推进同步进度。已确认对象在完整快照中缺失才进入删除处理，尚未上传对象和待确认编辑保留并按冲突规则处理。服务器/本地并发修改、编辑与删除冲突均显式呈现。工作区侧不得将查询失败、无权查看或未完成快照解释为用户解除关联。

重连顺序由 UC20 统一控制，先认证并清理已明确失权的范围，再查询未知结果回执、提交仍有权执行的命令，最后合并变化范围。私人课程、私人项目和共享项目均使用各自的工作区同步范围，快照只返回该工作区内当前授权可见的业务记录；私人工作区只授权本人。本人工作时段、剩余估时和计时摘要等私有执行数据从本人范围组合读取，不因工作区共享而进入共享快照。

## 3. 课程隐私投影与本地外键

UC02.3 要求无课程权限的项目成员看到“私人课程”。目前 `Workspace.linkedCourseId == null` 表示独立项目，`updateWorkspace(..., linkedCourseId = null)` 表示解除关联。共享账号适配层需要增加可区分的关系读取结果。

| 提议的 courseRelation 状态 | 可返回的信息 | 页面与编辑行为 |
| --- | --- | --- |
| NONE | 明确无关联 | 显示独立项目，可按权限选择课程 |
| ACCESSIBLE | 获授权课程的 ID、名称及归档状态 | 显示并可进入课程，按权限编辑关联 |
| PRIVATE | 只返回存在私人课程关联这一事实 | 显示“私人课程”，保留关系，隐藏名称与跳转目标 |

待确认的读取投影建议使用 `course_relation_state` 和仅指向可访问本地课程行的可空 `linked_course_id`。PRIVATE 时本地 ID 为空，关系真实值由服务器保存。未完成的关联课程加载保留读取中的状态，不转成 NONE。

写命令使用明确的 `Keep / Clear / Set(courseId)` 关联操作。保留不可见课程时发送 Keep。Clear/Set 由服务器重新校验操作者权限和目标课程状态。普通项目名称/说明编辑不会因读取投影的空 ID 而附带 Clear。编辑接口须区分字段未发送与显式清空。

当前 `WorkspaceEntity` 的 linked_course_id 自外键要求目标课程存在于本地 workspaces。PRIVATE 的真实课程行受权限限制，直接保存其原 ID 会触发外键失败。账号投影需评审上述字段与迁移，并遵守下列落库顺序。

- 可访问的课程与项目在外键满足后落库。依赖尚未获取完成时保留读取中的状态。
- 课程访问被撤销而项目仍可访问时，在同一事务先将依赖项目改为 PRIVATE 投影，再清理受限课程副本。
- 成员获得课程权限后，用授权快照补齐课程和 ACCESSIBLE 关系。只有明确的业务解除操作才能变为 NONE。
- 所有权交接后原私人课程的关系如何保留，由 UC14 与工作区负责人确认。交接不得使私人课程名称泄露给新所有者或其他成员。

当前本地唯一索引为 `(kind, name)`。账号库可能同时接收不同所有者的同名共享项目，接入前必须确认账号/服务端命名空间、比较方式、归档名称占用和对应迁移。建议读取投影允许表示来自不同所有者的合法同名项目，创建/编辑按团队确认的命名空间校验。此项确认及重复名称快照样例是账号接入前置条件。

## 4. 最小提供方接口提案

按空间绑定数据源，工作区页面消费以下语义即可。现有本地 WorkspaceDataSource 的方法可由 LOCAL 适配器继续使用。账号适配器需要完成事务队列、权限投影和状态映射。

| 提供方与提议操作 | 最小输入与输出 | 调用约束 |
| --- | --- | --- |
| UC01 `observeContext()` | 当前 SpaceContext、锁定/认证状态 | 账号模块统一拥有生命周期，凭据由其平台能力保管 |
| 工作区集成层 `bind(context)` | 得到固定空间的 WorkspaceProvider | 旧 generation 的实例拒绝新的写入，迟到结果无法发布到新空间 |
| WorkspaceProvider `observeDirectory(status, kind, query)` | 加载状态、工作区摘要及实际权限/同步状态 | 从所绑定本地空间读取，状态筛选与现有 ACTIVE/ARCHIVED 一致 |
| WorkspaceProvider `observeWorkspace(id)` | 工作区详情、courseRelation、可用操作、同步状态 | 区分加载中、成功、不可访问及读取失败；关联项目按同一授权范围查询 |
| WorkspaceProvider `submit(command)` | Create/Edit/Archive/Restore，编辑含 Keep/Clear/Set 和版本；返回记录 ID、operationId、本地确认版本或结构化失败 | account 模式必须在同一事务提交业务与队列，保留字段错误与草稿 |
| UC20 `observeOperation(operationId)`、`retry(operationId)` | 同步阶段、确认版本、冲突或失败 | 由同步模块查回执和重试，工作区接收结果并刷新相同记录 |
| UC14 权限变化通知 | 空间、generation、撤销/变更的工作区 ID | 触发页面与受限副本清理，并更新可执行操作 |
| UC12 摘要/详情接口 | 当前认证身份、查询条件/记录 ID，返回已授权且服务端确认的数据 | 每次请求鉴权，结果携带必要版本和权限信息 |

command 的身份来自绑定上下文。客户端提供输入校验与可用操作提示，服务器始终核验当前成员资格、归档状态及版本。字段验证、找不到记录、只读、无权限、需要认证、过期上下文、版本冲突和存储失败须能被调用方区分。现有本地编辑返回的 Boolean 只能表达当前命中结果，账号适配器需要补足上述语义。

## 5. 失权与安卓边界

服务器撤销成员后立即拒绝该成员后续项目读写和附件访问。桌面仅在收到服务端对指定工作区的明确撤权结果，或重连鉴权后确认该范围已失权时，关闭受限详情，移除目录/概览条目，并清理该范围的受限副本、草稿、缓存和队列正文。清理与工作区投影更新需要符合外键顺序。

会话过期或未认证（例如 401）、网络超时、服务不可达及 5xx 不等于工作区撤权，不得因此删除本地副本、草稿或待同步队列。会话失效按第 1 节暂停远端提交并重新认证；其他请求失败保留本地成果、显示失败并允许重试。不能将未成功取得的授权范围当成空范围执行清理。恢复服务及有效认证后，仍先核验权限，再按 UC20 查询未知结果回执和恢复同步，不因重试重新生成原操作 ID。

离线桌面可以使用此前已同步且尚未获知失权的共享快照，并显示最近同步时间。获知失权后执行清理，重连先鉴权再提交。私人时段、剩余估时、计时记录由各自模块按 UC17.3/BR12 保留、脱链或净化。工作区按其结果重新聚合本人可见记录。

安卓仅在已登录且在线时请求允许的工作区摘要及详情。检测到断网、服务不可达或会话失效后收起业务内容并停止操作，恢复后重新取数。桌面待同步修改在服务器确认后才能出现在安卓。项目摘要只含允许共享的内容，其他成员的私人时段、估时和计时明细保持私有。移动端的任务快速录入、状态变更、已有本人时段简单改期和番茄钟分别由 UC12 对应实现接入。
