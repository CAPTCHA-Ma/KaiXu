# Windows 桌面标题栏与导航

## 范围与结构

仅实现 Windows 的 JBR 自定义标题栏，复用现有任务、日程、工作区、记录和设置页面。不引入 Jewel，不升级数据库，不实现 Linux 窗口适配。

```text
Main → KaiXuWindow（真实窗口、JBR 生命周期）
          → DesktopApp（依赖与主题）
              → DesktopNavigation（统一导航、访问历史）
                  → DesktopShell
                      ├── DesktopTitleBar
                      └── DesktopSidebar 与 NavHost
```

`WindowsTitleBarState` 为单个窗口提供原生按钮占用宽度及鼠标区域判定，在窗口释放时解除 JBR 标题栏和监听器。`Window` 保持默认装饰模式，不设置 `undecorated=true`。Windows 上运行时检查 JBR 的 `WindowDecorations` 服务；未使用支持此服务的 JBR 时报告明确错误。非 Windows 进程仅用于编译与业务界面测试，不代表完成其他平台的窗口集成。

## 外观

顶部固定 45 dp 高；左侧依次为设置、返回、前进，按钮为 31.5 dp（高度 70%）、圆角 8 dp，间隔 6 dp。色板和框架尺寸集中在 `DesktopChromeColors`：

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| color0 | `#F3F3F3` | 标题栏、侧栏、框架按钮和原生窗口按钮默认背景 |
| color1 | `#DEDEDE` | 框架按钮悬停、按下或选中背景、窗口按钮悬停/按下背景 |
| color2 | `#656565` | 未选中图标、原生窗口按钮图标 |
| color3 | `#000000` | 框架按钮选中图标 |

框架按钮默认背景与边栏一致，图标为灰色；悬停或按下时背景略深，图标仍为灰色；选中后保持相同的略深背景，图标变为黑色。设置页打开时齿轮按钮持续选中，侧栏按钮随当前页面切换选中状态。没有后退/前进历史时对应按钮禁用，保持默认背景，图标降低不透明度。右侧保留 JBR 提供的最小化、最大化/还原和关闭按钮，通过 `controls.*` 属性设色，不绘制另一套 Compose 窗口按钮。

标题栏左侧按钮区域接收 Compose 点击；空白区域将每次鼠标事件标记为原生标题栏区域，从而保留原生拖动和双击最大化。Compose 以窗口实际按钮占用宽度留出左右空位。

侧栏宽度为 52 dp，内边距 8 dp，顶部直接纵向排列任务清单、日历、文件夹三个线框图标，分别进入“任务 / 日程 / 工作区”，间隔 6 dp；不再显示品牌标题或侧边分隔线。侧栏与标题栏使用同一背景色，视觉上连成一体。导航按钮为 36 × 36 dp 的圆角正方形，略大于标题栏的 31.5 dp 按钮，图标为 20 dp；保留中文无障碍名称，与标题栏通过 `DesktopChromeButton` 共用圆角、默认色、悬停、按下及选中反馈。页面路由、数据源可用性判断与前进后退历史保持现有规则。

标题栏中心通过 `DesktopTitleCaption` 显示当前页面名称：任务、日程、工作区、设置，以及任务/事件/资源详情。标题相对整个窗口居中，左右对称避让工具按钮和原生窗口按钮，中心区域仍可拖动窗口。

悬停顶部或侧栏按钮时，目标页面名称从右侧缓入，暂停在替换过程的 72% 位置。新标题独立绘制并预留完整宽度，旧标题向左移动，整段文字应用从左透明到右侧较清晰的渐变；不再使用窄裁剪区、前景遮挡面板或局部背景阴影。点击确认时旧标题继续整体淡出，新标题移至中心，常规动画约 300 ms。

离开按钮后等待 180 ms 才启动恢复动画。在这段宽限时间内进入另一个按钮，保持页面标题的淡出状态，新预览文字从上方进入、旧预览文字向下退出，纵向动画约 220 ms。每层文字独立完成退场，连续切换时不先回弹，也不会把正在退出的文字拉回起点；长短标题的占位宽度平滑调整。离开所有按钮超过宽限时间后才反向缓出。时间参数集中在 `DesktopTitleCaption.kt` 的 `HoverExitGraceMillis` 和 `PreviewRollDurationMillis`。

返回/前进按钮预览其目标页面，禁用按钮与当前页面按钮不产生额外预览。悬停不更改路由或历史，点击后本次悬停被消耗，避免鼠标留在按钮上时覆盖真实页面标题。

## 导航规则

`DesktopNavigator` 是主页面、设置和记录详情之间跳转的统一入口。左侧导航、顶部设置按钮、页面原有设置入口和详情返回按钮都使用同一份窗口访问历史：

- 后退/前进按实际访问次序移动，记录详情保存具体种类和 ID。
- 后退后进入新页面会清除前进分支；重复点击当前页面不添加历史。
- 任务页保留为稳定根条目，任务草稿和保存状态保持；工作区与日程继续使用 Navigation 的保存/恢复机制。
- 带 ID 的记录详情重新读取对应记录，不按共享路由类型恢复旧参数。详情中尚未保存的编辑弹窗不作为历史页面保留。
- 工作区内部的详情切换、页签、筛选和编辑弹窗仍属于原页面内部状态；本轮没有把这些内部操作逐一转成历史条目。后续扩展页面时应继续接入统一导航入口。
- 历史仅在当前窗口会话内存在，不写入数据库。
