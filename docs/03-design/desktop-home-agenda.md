# 桌面首页卡片日程（Issue #24）

## 首版视觉与交互

首页左侧直接显示卡片，移除外层容器背景、边框、标题、日期和上下辅助按钮及说明文字。区域宽度保持可用内容宽度的 62%，高度为页面内容区的约 80%，垂直居中，上下各预留约 10% 用于其他内容；可用宽度小于 720 dp 时占满宽度。矮窗口以 340 dp 为区域最小高度（不超过页面高度），优先容纳中央三张完整卡片。右侧预留后续推送位置。中央卡片圆角 18 dp、高 104 dp，卡片宽度规则不变，布局参数集中在 `HomeScreen.kt` 的 `HomeAgendaStyle`。

卡片按时间从上到下排列，以低饱和色区分固定事件、个人时段和任务截止。每张卡片显示时间或“当天截止”、日期、标题、类型、可用工作区和必要状态；移除重复的个人归属、补充说明和“查看”小字，点击仍进入既有原记录详情。个人时段显示关联任务标题，但点击打开该时段，避免把结束时段误当成完成任务。

`AgendaTimeline` 按轮式布局绘制中央附近最多十一张卡片，由滚轮输入切换整数事项目标；每一格切换一个事项，精细滚轮的小数输入先累计。复用 `CardScrollMotion` 的连续索引作为动画位置，停稳后完整卡片回到中央。槽位位置由卡片高度和固定间距决定，不随视口高度拉伸；窗口缩放时重新居中。

`WheelCardPose` 统一计算每张卡片的缩放、纵向位置、阴影和整卡透明度。缩放锚点固定在左侧中点，所有卡片左边缘对齐，右边缘逐级向内缩进；移除旧的横向平移和透视倾斜。中央卡片完整展开，相邻卡片约为 95% 大小、第二层约 88%。对平滑缩放后的卡片高度积分，使整数槽位的边缘间距固定为 14 dp；位置计算不依赖视口高度，不同窗口下保持相同间距。

视口高度只用于边缘淡出：高窗口显示更多卡片，矮窗口显示更少卡片，不改变卡片尺寸或拉伸间距。卡片先完整淡出，再移出绘制窗口，避免平面列表的边缘裁切感。动画位置在图形图层中读取，逐帧变换不重建卡片文字；只有可见索引窗口变化时调整绘制条目。

透明度作用于整张卡片，移除纵向渐变遮罩。中央及上下相邻槽位保持 100% 不透明，不受距离和边缘淡出影响。更外侧卡片才逐渐淡出，距离衰减系数保持 0.075；边缘淡出长度随视口剩余空间缩短，避免缩小区域后冲淡中央三张。同一张卡片的底色不因槽位变化而改变，悬停也不叠加 Material 灰色色层。几乎完全透明的卡片不会打开记录。

初次载入时，正在发生的未完成安排优先居中，否则选择距当前时刻最近的未完成事项，再回退到历史记录。首尾条目同样能居中。使用事项 key 保存当前浏览目标，导航返回、正常时钟更新和同条记录刷新保留该目标。

## 悬停跟随

指针进入可见卡片时，卡片围绕自身中心轻微放大 1.8%，阴影增加 3 dp。根据指针在卡片内的相对位置，卡片向同方向偏移，水平最多 6 dp、垂直最多 4 dp。放大与跟随均使用临界阻尼弹簧（刚度分别为 280、240），连续移动时平滑更新目标，移出后平滑恢复原尺寸和槽位。

外层负责滚轮变换和稳定的鼠标感应区域，内层负责悬停放大、偏移及阴影，避免视觉位移反馈到鼠标感应区域导致反复进出。悬停卡片提高绘制层级，不改变原底色或透明度规则。滚轮输入清除悬停，切换期间暂停跟随；停稳后再次移动指针即可恢复悬停。几乎完全透明的卡片不响应悬停。点击打开原记录沿用现有入口，并在主线程执行导航。

滚轮绘制区域按卡片宽度、悬停放大比例与最大横向偏移扩展左右裁剪边界，另留阴影余量，防止宽窗口下卡片左移时圆角和卡面被截断；不改变卡片原尺寸、左对齐位置或偏移幅度。上下仍严格裁剪，预留区域不接收卡片流滚轮输入。悬停缩放与位移参数集中在 `HomeAgendaStyle`，绘制余量和动画共用同一组参数。

## 阻尼与连续切换动画

`CardScrollMotion` 是独立于日程数据的运动控制器，以卡片索引为单位记录连续位置、速度和整卡目标。小于一格的输入先产生最多 0.10 个索引单位的阻尼预移；累计达到一格后提交下一张卡片。没有达到阈值便停止输入时，卡片缓慢回到原来的位置。

达到阈值后，使用固有角频率 20 rad/s、阻尼比 0.74 的欠阻尼弹簧；单张切换约 180 ms 到达中央，随后越过约 3.2% 卡片间距（约 4 dp），再被拉回，约 500 ms 停稳。越过落点时右边缘随过冲轻微展开（单张约 0.6%，上限 1.44%），回位后恢复原宽度，左侧始终固定。上下切换对称，避免持续摇晃或夸张拉伸。

连续输入只改变同一个弹簧的目标，保留当前位置和速度；速度上限为每秒 22 张，中间经过的事项不单独启动动画。小数输入没有提交新目标时不重启弹射，阈值前的预移使用临界阻尼。首尾允许不超过 0.12 个索引的视觉越界，目标索引仍限制在已有事项内，不触发额外导航。移除旧巡航与强制停止分支，相关参数集中在 `CardScrollMotion` 的 companion object。

界面用同一个 Channel 和帧循环处理一整段滚轮输入，每帧合并目标更新；没有为每一格启动独立动画。数据结构变化或窗口缩放时取消旧运动，按保存的事项重新居中，避免旧索引影响新布局。动画不改变昨天至明天的查询范围及边界导航规则。

## 时间范围与边界

窗口为当前本地日期前一天零点到后两天零点的半开区间，即昨天、今天、明天三个自然日。沿用现有 `ShanghaiTime` 的 UTC+8 日期口径。与窗口相交的事件和本人时段也会保留。没有截止日期的任务不伪造时间、不塞入时间线；只有日期的截止排在当天末尾，界面显示“当天截止”。任务截止与执行时段可以同时出现，类型标识不同。

列表首尾不会无限加载。到达边界后，继续同方向滚轮输入累计约六格才进入现有日程页；中途转向或相隔超过 800 ms 会重置累计。范围内正常切换不会触发导航。滚轮输入由列表的指针处理器统一消费，避免默认滚动与整卡切换叠加；导航使用主线程调度，并保留窗口访问历史。

## 数据与复用

`HomeRoute → HomeViewModel → shared AgendaUseCase → 现有本地 DataSource`。数据聚合在 shared，可由其他端或其他日程视图复用；没有新增数据库表、迁移或运行依赖。

固定事件复用 `Recurrence.expand` 展开课次和取消例外，窗口过滤后不显示越界课次；本人时段通过已有按身份和时间范围的查询获取，取消时段不展示，保留已完成历史。工作区名称包含归档标识。任务只展示本人创建或分配给本人的记录，其他用户的个人时段不进入结果。

首页每次恢复至前台时刷新数据，每 30 秒更新时间；跨日重新读取三天窗口。读取失败提供重试入口。详情使用已有 `LocalRecordTarget` 和统一导航，不复制编辑表单。

## 演示数据

正常启动不会自动插入演示数据。在 `apps/client` 目录显式运行：

```powershell
.\gradlew.bat -PdesktopOnly=true :desktopApp:seedHomeAgendaPreview
```

命令通过现有 Room DataSource，在桌面默认本地库创建三天的 29 条预览安排（任务截止、事件与时段的合计），标题含 `[预览]`，说明含“首页布局预览数据”。使用稳定 ID，重复执行不会重复插入，不修改既有记录。启动时刻附近额外安排一个个人时段，方便观察居中与强调效果。测试工具仅在 test 源集中，不进入桌面发布包。

需要隔离数据时，可传 `-PpreviewDatabase=D:/path/to/preview.db`。UI 自动测试始终使用临时隔离库，结束后清理。
