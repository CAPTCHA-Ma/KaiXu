# KaiXu UI/UX 设计

> 目标：把“收集 → 确认 → 安排 → 执行 → 反馈”做成低打断、可恢复的双端体验。  
> 桌面承担完整管理；Android 只承担在线查看、快速录入、状态更新、简单改期和番茄钟。  
> 高保真静态原型：[prototype/index.html](prototype/index.html)

## 1 设计原则

1. **先回答“今天做什么”**：首页优先展示今天的时间线、临近截止和未排期任务，而不是统计报表。
2. **共享与私密一眼可辨**：共享任务/事件用“共享”标识；本人时段、剩余估时、番茄钟用“仅我”标识，并在文案中解释不会共享。
3. **确认前不写正式数据**：候选、排程草案、AI 建议都在侧栏/对话框内预览，主按钮明确“确认创建/接受”，取消不留痕。
4. **状态永远可见**：本地保存、待同步、同步中、已同步、冲突、失败都有持久状态，不把失败显示成成功。
5. **保留输入**：任何校验失败、断网、版本冲突都不清空表单；错误就地说明并给出下一步。
6. **桌面高密度、移动低密度**：桌面用双栏/三栏和键盘快捷键；Android 单列、底部导航、48dp 触控目标。
7. **少用颜色单独传达信息**：类型、截止精度、隐私、同步状态同时用文字/图标表达（WCAG 1.4.1）。

## 2 信息架构

### 2.1 桌面导航

```text
┌──────────────────────────────────────────────────────────────────────────┐
│  KaiXu  [全局搜索…]                         [同步状态] [通知] [头像]      │
├──────────────┬───────────────────────────────────────────────────────────┤
│ 今天          │                                                           │
│ 任务          │                                                           │
│ 日程          │                        主内容区                            │
│ 工作区        │                                                           │
│ 收件箱    ③   │                                                           │
│ 来源连接      │                                                           │
│ ──────────   │                                                           │
│ 设置 / AI     │                                                           │
└──────────────┴───────────────────────────────────────────────────────────┘
```

- 侧栏宽 248px，可折叠为 72px 图标栏。
- 全局搜索 `Ctrl/Cmd + K`：任务、事件、工作区、资料；结果分组，回车打开。
- 同步状态 chip 常驻右上；点击展开待同步队列/冲突。
- 收件箱角标只显示待确认候选数量，不显示已忽略。
- 详情页保留面包屑：`工作区 / 课程名 / 任务标题`，提供返回入口。

### 2.2 Android 导航

```text
┌─────────────────────────────┐
│ 今天                   🔔  │
│                             │
│       单列内容区            │
│                             │
├─────────────────────────────┤
```

- 底部导航 5 项；番茄钟从任务详情/今日时段进入全屏计时。

- 离线/未登录时业务区替换为状态页，不显示缓存内容。

## 5 关键交互

### 5.1 完成任务：先处理未来时段

```text
┌──────────────────────────────────────────────┐
│ 完成任务：完成课程项目原型                   │
│                                              │
│ 你还有 2 个未来时段：                        │
│  • 11/05 19:00–20:00                         │
│  • 11/06 19:00–20:30                         │
│                                              │
│ 历史时段会保留；其他成员的时段不受影响。     │
│                                              │
│ ( ) 保留这些未来时段                         │
│ (•) 取消这些未来时段                         │
│                                              │
│ [暂不完成]              [确认完成]           │
└──────────────────────────────────────────────┘
```

- 打开对话框时**不写**任务状态；关闭/暂不完成不产生变更。
- 确认后任务状态与本人未来时段同一事务提交；失败保留选择，可幂等重试。
- 恢复未完成不会自动重建已取消时段。

### 5.2 版本冲突：保留草稿 + 三列比较

```text
┌──────────────────────────────────────────────────────────────┐
│ 这条记录已被其他端修改                                       │
│ 你的修改已保留。请比较后再保存。                             │
├────────────────┬────────────────┬────────────────────────────┤
│ 基准版本 v7    │ 我的输入        │ 服务端最新 v8              │
│ 截止 11/10     │ 截止 11/12      │ 截止 11/11                 │
│ 标题 原型      │ 标题 原型 v2    │ 标题 原型                  │
├────────────────┴────────────────┴────────────────────────────┤
│ [放弃我的修改]  [保留我的输入并重试]  [逐字段选择…]          │
└──────────────────────────────────────────────────────────────┘
```

- 冲突时不清空输入；不自动合并。
- 提交时以服务端最新 `version` 为新基准。
- 删除与编辑竞争：提示“记录已删除”，允许把本地内容另存为草稿或放弃。

### 5.3 离线与同步状态

| 状态 | 界面表现 | 可用动作 |
| --- | --- | --- |
| 未登录本地 | 顶栏“仅本地 · 不会上传” | 完整个人工作流；登录后导入账号 |
| 待同步 | “已保存到本地 · 待同步 3” | 查看队列、手动重试 |
| 同步中 | 旋转图标 + “同步中” | 可继续本地编辑 |
| 已同步 | 对勾 + 最近同步时间 | 查看详情 |
| 冲突 | 警示 chip + 角标 | 比较、重提 |
| 失败 | 红色 chip + 原因 | 重试、查看请求 ID |
| Android 断网 | 全页状态说明 | 重连后重取；不显示缓存 |
| 权限失效 | 共享内容替换为说明 | 返回工作区；私人脱链记录仍可看 |

### 5.4 候选确认

- 左侧候选列表、中间原文、右侧字段；确认按钮只在字段完整时可用。
- 日期不明确时突出“需补充日期”，不能默认一个时间。
- 字段变更逐项勾选；接受后保留负责人、私人时段、资料关联。
- 疑似重复提供“打开已有任务 / 忽略候选”，不创建新任务。
- 来源撤回只提示，不直接删除本地任务。

### 5.5 AI 建议

```text
┌──────────────────────────────────────────────┐
│ AI 建议 · 资料关联                           │
│ 将发送：任务标题、描述、候选资料名称/摘要    │
│ 接收方：api.example.com（你配置的服务）      │
│ [查看完整发送内容]                           │
│                                              │
│ ☑ 需求说明书  相关性 0.92  “包含验收标准”    │
│ ☑ 访谈记录    相关性 0.81  “用户场景”        │
│ ☐ 原型说明    相关性 0.55                    │
│                                              │
│ [取消]                    [采纳所选]         │
└──────────────────────────────────────────────┘
```

- 调用前展示接收方与数据范围；未选择的内容不发送。
- 结果只是建议；采纳后才写入任务/阶段/估时。
- AI 失败/超时/取消不阻塞人工流程；晚到结果丢弃。
- 共享项目的私人时段、番茄钟、未选文件不进入上下文。

状态色只用于语义；共享/私人同时用文字标签，不仅靠颜色。

### 6.2 字体

| 层级 | 桌面 | Android | 用途 |
| --- | --- | --- | --- |
| Display | 28/36, 600 | 24sp/32, 600 | 页面大标题（少量） |
| H1 | 24/32, 600 | 22sp/28, 600 | 页面标题 |
| H2 | 18/26, 600 | 18sp/24, 600 | 区块标题 |
| Body | 14/22, 400 | 16sp/24, 400 | 正文/表单 |

字体族：`Inter, "Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif`。中文优先使用系统字体，避免包体过大。

### 6.3 间距、圆角、阴影

- 间距基数 4：`4 / 8 / 12 / 16 / 24 / 32 / 48`。
- 卡片圆角 14；输入/按钮 10；标签 999（胶囊）。
- 阴影：`0 1px 2px rgba(22,32,51,.06), 0 8px 24px rgba(22,32,51,.06)`；深色模式降低不透明度。
- 桌面内容最大宽 1280，阅读型表单最大 720；Android 水平边距 16。

### 6.4 组件

| 组件 | 规范 |
| --- | --- |
| 按钮 | 主按钮实心 primary；次按钮描边；危险操作 danger 且需确认；高度桌面 36/40，Android 48 |
| 输入 | 标签在上；错误在下方；必填用 `*` + 说明；不只用 placeholder |
| 状态标签 | `待办/进行中/已完成`；`共享/仅我`；`仅日期/具体时间` |
| 同步 chip | 图标 + 文本 + 数量；点击打开队列 |
| 日期选择 | 日期与时间分开；提供“仅日期”开关；显示 Asia/Shanghai |
| 空状态 | 一句解释 + 一个主行动 |
| 对话框 | 标题、影响说明、取消/确认；危险操作默认焦点在取消 |
| Toast | 只用于轻提示；保存/同步状态用持久 chip，不用瞬时 toast |
| 表格/列表 | 行高 44；悬停高亮；键盘可聚焦 |

### 6.5 图标与插画

- 线性图标 1.5px，24px 网格；使用 Lucide（桌面）与 Material Symbols（Android）同一语义。
- 空状态可用简单几何插画，不使用大幅装饰图；避免喧宾夺主。
- 共享/私人图标：`users` / `lock`；同步：`cloud`, `cloud-off`, `refresh-cw`, `alert-triangle`。

## 7 响应式与无障碍

### 7.1 断点

| 宽度 | 布局 |
| --- | --- |
| ≥ 1200 | 侧栏 + 主内容 + 右栏 |
| 900–1199 | 侧栏 + 主内容；右栏折叠为抽屉 |
| 600–899 | 图标侧栏 + 单列；表格转卡片 |
| < 600（Android/窄窗） | 单列 + 底部导航；不使用桌面周网格 |

### 7.2 无障碍

- Android 主要触控目标 ≥ 48×48dp；桌面可点击行高 ≥ 40。
- 正文对比度 ≥ 4.5:1；大字/图标 ≥ 3:1。
- 支持 130% 字体缩放；不截断关键操作；表格可横向滚动。
- 键盘：Tab 顺序合理；`Ctrl/Cmd+K` 搜索；`Esc` 关闭抽屉；焦点可见。
- 表单错误与字段关联（`aria-describedby` / Compose semantics）；状态消息可被读屏播报。
- 尊重“减少动态效果”；动画 150–200ms，避免大幅位移。
- 不用颜色单独表达状态；图标 + 文本 + 形状。

## 8 文案与状态

| 场景 | 推荐文案 | 避免 |
| --- | --- | --- |
| 本地保存 | 已保存到本地，联网后自动同步 | 已保存（未说明是否上传） |
| 未登录 | 仅本地使用，不会上传到服务器 | 请登录（阻断个人流程） |
| 同步失败 | 同步失败：网络不可用。你的修改仍在本地。[重试] | 保存失败（未说明数据是否保留） |
| 冲突 | 记录已被其他端修改，你的输入已保留。 | 保存失败：409 |
| 权限失效 | 你已不在该项目中，共享内容已不可访问。 | 403 Forbidden |
| 附件失败 | 上传未完成，当前版本未被替换。[重试] | 上传失败 |
| 番茄钟未达标 | 本次计时未达到 70%，你仍可完成任务。 | 未完成/失败 |
| 空收件箱 | 没有待确认的事项。可手动粘贴或连接来源。 | 暂无数据 |
| 归档 | 已归档，内容只读，可随时恢复。 | 已删除 |

## 9 高保真原型

静态原型位于 [prototype/index.html](prototype/index.html)，可直接用浏览器打开：

- 桌面：今天、任务详情、周视图、收件箱、项目看板。
- Android：今天、任务详情、番茄钟。
- 使用同一套设计 token；演示数据为虚构内容。
- 原型只表达信息层级、视觉与交互状态，不代表真实接口/权限/同步已实现。

## 10 UI/UX 验收清单

- [ ] 从主页面快速创建独立任务不超过 4 个主要动作（输入除外），双端分别记录。
- [ ] 任务详情清楚显示工作区、来源、状态、截止精度、共享/仅我。
- [ ] 从任务详情打开关联资料不超过 2 个主要动作；无关联时有明确提示。
- [ ] Android 主要触控目标 ≥48×48dp；130% 字体下核心操作可用。
- [ ] 保存失败/断网/权限过期时输入不清空，错误说明原因和下一步。
- [ ] 完成对话框在确认前不写状态；取消后任务与时段不变。
- [ ] 版本冲突可比较基准/本地/服务端并重提。
- [ ] 共享页面不显示他人私人时段/剩余估时/番茄钟；私人字段有“仅我”标签。
- [ ] 收件箱候选确认前不创建正式任务；忽略不产生记录。
- [ ] AI 建议调用前展示数据范围；取消/失败可回到人工流程。
- [ ] 空状态、离线、归档、权限失效均有明确说明与恢复入口。
- [ ] 状态不只靠颜色表达；键盘/读屏可用；减少动态效果生效。
