# 新增个人任务示例验收

前置：启动任一端应用，任务列表为空；关闭重开会重置内存，不执行跨设备同步验收。

| 场景 | 操作 | 期望 |
| --- | --- | --- |
| 空输入 | 输入空格后保存 | 提示请输入标题；列表仍为空，输入保留 |
| 正常创建 | 输入“  准备访谈  ”后保存 | 保存期间不可重复提交；成功列表显示“准备访谈”，输入清空 |
| 失败恢复 | 点击模拟失败，输入“准备演示”并保存 | 提示失败；列表不增加，草稿仍在 |
| 重试 | 保持失败草稿再次保存 | 恰好增加一项，错误清除 |
| 取消 | 输入标题，保存中立即取消 | 当前内存实现不新增任务，输入保留 |
| 超长 | 输入121个“字”后保存 | 提示超过长度，列表不变 |


## 导航往返

1. 输入标题但不保存，点击“打开设置”，确认显示“设置与说明”。
2. 点击“返回任务”，原草稿仍显示。
3. 保存一条任务，再往返设置页，任务数量和列表保持不变。
4. 模拟保存失败后往返设置页，错误与草稿仍在；再保存应成功且只增加一条。
5. Android 上另验证系统返回键回到任务页；任务根页面再返回保持平台正常退出行为。

桌面自动化覆盖前四项；Android 系统返回仍需设备验收。应用重启会清空内存，不将导航往返保留与持久化混淆。
