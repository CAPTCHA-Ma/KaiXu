# 数据库版本迁移

此目录存放手写 Kotlin 迁移，自动迁移注册在 [KaiXuDatabase.kt](../KaiXuDatabase.kt)。
历次结构变化和验收证据见 [客户端变更记录](../../../../../../../../../../../../../CHANGELOG.md)。

`Migration1To2` 已注册在 DatabaseFactory，负责从最小任务表升级到三表结构：
保留任务标题、将整数 ID 转为 UUID、补入默认字段并建立固定事件和个人工作时段表及索引。
旧库没有创建时间，因此时间为迁移时补入，不能视为历史真实创建时间。

旧版没有关联表，转换主键不涉及外部引用。v2→v3 和 v3→v4 分别自动新增工作区表、资料表，保留迁移前的旧表与数据。
以后新增迁移时必须考虑已有外键和数据，并在同一个 PR 补变更记录、结构快照和升级验证。
历史版本应保持固定，后续变更继续递增版本并新增迁移，不修改已经交付的转换。
