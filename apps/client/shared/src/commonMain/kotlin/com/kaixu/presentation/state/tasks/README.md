# 任务页面状态

当前 `TaskEditorUiState.kt` 包含 `draftTitle`、已确认的 `tasks`、`isLoading`、`isSaving`、错误与成功消息。任务列表来自仓储，草稿与保存提示由 ViewModel 管理。

后续截止日期、估时、优先级等编辑字段放表单状态；已保存的业务字段放 domain model。不要给服务器 TaskDto 加 `isSaving`。

失败保留草稿，成功才清草稿；版本冲突需要同时保存“我的草稿”和“服务端最新记录”，不能用最新记录直接覆盖用户输入。

## 共享条件

当前两个标题录入页面共用此状态。以后完整任务编辑与快捷录入若需要不同字段，可在各端分别建立状态类，业务 Task 和校验规则继续共用，无需强制继承同一个页面状态基类。
