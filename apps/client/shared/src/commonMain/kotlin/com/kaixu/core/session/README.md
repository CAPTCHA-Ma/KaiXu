# 账号会话边界 预留

后续写 SessionStore 接口、当前账号标识、会话有效性和清理流程。安全令牌的具体存取委托平台实现，不让各个 ViewModel 独自管理令牌。

登录后按账号构建数据范围；退出或换号使旧请求失效、清空页面状态并隔离旧缓存。两端 AppContainer 当前只是演示依赖容器，还没有实现账号会话。

本地会话不代替后端鉴权，也不能因为隐藏按钮就允许缓存中的共享记录继续开放。

## 适宜存放的文件

可增加 AccountSession.kt、SessionStore.kt、账号切换清理协调代码。两端 app 下的 AppContainer 当前只保存演示依赖图；不要用它代替已经设计好的真实登录、退出与缓存隔离流程。
