# 任务输入规则

`TaskTitle.kt` 检查去除两端空白后的标题：必填，最多120字符。120是现有演示约定，SRS仅明确必填，不要把它当作已签订的正式 API 限制。

修改边界时同时检查 `contracts/rules-fixtures/task-title.json` 与测试。正式客户端和服务端应对字符长度口径达成一致；Kotlin String.length 的 UTF-16 长度不等同于所有语言的 Unicode 字符计数。

## 适宜增加的规则

任务标题、已明确的估时范围等纯检查可各自建 .kt 文件。依赖当前账号权限或服务端最新版本的判断不能假装为静态校验；必须通过相应业务接口确认。
