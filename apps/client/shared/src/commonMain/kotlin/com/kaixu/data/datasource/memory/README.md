# 内存演示数据源

`InMemoryTaskDataSource.kt` 用进程内列表模拟服务端，包含600毫秒延迟、失败开关和顺序 ID。失败发生在实际写入前。

它用于学习、演示和可控测试；关闭应用数据丢失，另一端无法看到数据。取消等待可阻止此实现写入，但不能据此推断真实 HTTP 服务也支持回滚。

后续保留为开发替身；正式环境由 app/di 接入远程实现，页面和 UseCase 无须导入此类。

## 适宜存放的文件

可放按业务命名的 InMemoryWorkspaceDataSource.kt 等演示替身，以及可控失败或延迟设施。仅为某个测试使用的 Fake 类优先放 commonTest，避免进入正式分发代码。
