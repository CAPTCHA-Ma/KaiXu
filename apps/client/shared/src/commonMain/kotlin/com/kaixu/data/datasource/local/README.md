# 本地缓存数据源 预留

后续写个人缓存的 DAO、Entity 和本地读写适配。可选数据库或文件方案，选定后再加依赖；当前没有持久化实现。

依 SRS FR-X05，仅缓存个人内容并展示更新时间；离线只读，共享内容需在线鉴权，不支持离线新建、修改或自动补交。按 accountId 隔离，退出清会话并隔离旧数据。

Entity 只描述缓存格式，转换后返回业务对象，不把 SQL 类型交给 UI。不要把服务器数据库连接信息放在客户端。

## 平台差异的放置

通用缓存接口、Entity 和转换逻辑可在 commonMain；需要 Android Context 或 JVM 路径的驱动初始化放平台源集或 App，通过接口注入。这里不放页面草稿，也不代表已经有离线编辑能力。
