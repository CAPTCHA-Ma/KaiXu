# 可复用校验

写不访问网络、文件或界面的纯规则，例如标题是否有效、结束是否晚于开始、两个半开时间区间是否重叠。按业务建立子包。

规则可以被 ViewModel 用于即时提示，也被 UseCase 调用。规则参数和返回值应便于单独测试，服务器必须独立执行最终校验。

当前 TaskTitle 返回中文提示以保持示例简洁；需要多语言时改为错误类型或错误码，再由表现层转换文字。

## 文件命名与协作

建议按规则命名，例如 tasks/TaskTitle.kt、scheduling/TimeRangeRules.kt。相同边界由两端共用；与界面颜色、控件可用性有关的展示判断放表现层，与 HTTP 响应字段转换有关的判断放 mapper。
